# My Full Stack App

This is a full-stack web application built with:

- React (Vite) frontend  
- Express.js backend  
- Prisma ORM  
- SQLite/PostgreSQL database  

## Features

- User dashboard UI  
- API integration  
- Add + fetch users  
- Insights + Activity pages  

## Run Locally

### Backend

```bash
cd server
npm install
npm run dev
