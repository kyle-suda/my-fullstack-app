# Security Policy

## Supported Version

Security fixes are applied to the latest version on the `main` branch and the
currently deployed application.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Email
`kyle.sudaa@gmail.com` with:

- the affected URL, endpoint, or component;
- clear reproduction steps;
- the potential impact; and
- any suggested remediation.

Do not access or modify another person's data, disrupt the service, or perform
high-volume testing. Please allow reasonable time to investigate and remediate
the issue before public disclosure.
